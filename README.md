
# بوابة أهالي مخيم أبو عريبان

## الحالة الحالية
نسخة واجهة تجريبية لاختبار التصميم وتجربة المستخدم.

## طريقة التجربة
1. افتح البوابة بعد نشرها.
2. أدخل رقم الهوية التجريبي: `123456789`
3. أدخل سنة الميلاد التجريبية: `1985`
4. جرّب عرض الملف وإرسال طلب أو شكوى.

## تنبيه
- البيانات المعروضة وهمية.
- الطلبات تُحفظ في المتصفح فقط.
- لا يوجد اتصال حاليًا بقاعدة بيانات المخيم.
- لا تستخدم بيانات شخصية أو أرقام هويات حقيقية في هذه النسخة.

## الخطوة التالية
إنشاء وربط خادم API آمن بقاعدة بيانات D1 الحالية، والتحقق من أن كل أسرة لا تستطيع الوصول إلا إلى بياناتها، وأن الطلبات الجديدة تبقى بانتظار مراجعة الإدارة.
